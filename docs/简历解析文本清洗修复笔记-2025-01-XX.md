## 问题描述

### 问题1：隐私脱敏使用占位符
- **现象**：文本清洗时，手机号、邮箱、身份证号被替换为 `[手机号]`、`[邮箱]`、`[身份证号]` 占位符
- **问题**：用户不需要这些占位符，应该直接删除

### 问题2：简历解析标题重复和位置错误
- **现象**：
  - `## 实习经历`、`## 项目经验`、`## 技能清单` 等标题出现重复
  - 标题位置错误，出现在内容后面而不是前面
  - 例如：先出现工作内容，然后才出现 `## 实习经历` 标题
- **问题**：解析逻辑没有正确处理标题的位置和去重

## 修复方案

### 修复1：隐私脱敏直接删除

**文件**: `TextProcessingService.java`

**修改前**:
```java
// 隐私脱敏：用占位符替换，而不是直接删除，保持文本结构
// 替换手机号
text = text.replaceAll("1[3-9]\\d{9}", "[手机号]");
// 替换邮箱
text = text.replaceAll("\\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\\.[A-Z|a-z]{2,}\\b", "[邮箱]");
// 替换身份证号
text = text.replaceAll("\\d{17}[\\dXx]", "[身份证号]");
```

**修改后**:
```java
// 隐私脱敏：直接删除手机号、邮箱、身份证号
// 删除手机号
text = text.replaceAll("1[3-9]\\d{9}", "");
// 删除邮箱
text = text.replaceAll("\\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\\.[A-Z|a-z]{2,}\\b", "");
// 删除身份证号
text = text.replaceAll("\\d{17}[\\dXx]", "");
```

**效果**：
- 隐私信息被直接删除，不留占位符
- 保持文本结构完整性

### 修复2：简历解析标题位置和去重

**文件**: `ResumeService.java`

#### 2.1 检测已有的 Markdown 标题

**新增逻辑**：
```java
// 检测是否已经是 Markdown 二级标题（## 标题）
if (trimLine.startsWith("## ")) {
    String titleText = trimLine.substring(3).trim();
    // 标准化标题名称
    if (titleText.contains("实习") || titleText.equals("实习经历")) {
        if (!hasAddedInternshipHeader) {
            result.append("\n## 实习经历\n");
            hasAddedInternshipHeader = true;
            currentSectionType = "实习经历";
            inValueSection = true;
        }
    } else if (titleText.contains("项目") || titleText.equals("项目经验")) {
        if (!hasAddedProjectHeader) {
            result.append("\n## 项目经验\n");
            hasAddedProjectHeader = true;
            currentSectionType = "项目经验";
            inValueSection = true;
        }
    } else if (titleText.contains("技能") || titleText.contains("技术") || titleText.equals("技能清单")) {
        if (!hasAddedSkillHeader) {
            result.append("\n## 技能清单\n");
            hasAddedSkillHeader = true;
            currentSectionType = "技能清单";
            inValueSection = true;
        }
    }
    continue;  // 跳过原始标题行，避免重复
}
```

**作用**：
- 如果原始简历中已有 `## 实习经历` 等标题，直接使用，不重复添加
- 标准化标题名称，统一为"实习经历"、"项目经验"、"技能清单"

#### 2.2 确保标题在内容前面

**修改逻辑**：
```java
// 项目/工作标题行（包含时间和职位）
if (isWorkProjectTitle(trimLine)) {
    inValueSection = true;
    
    // 判断是实习还是项目
    boolean isInternship = trimLine.contains("实习") || trimLine.contains("实习生");
    
    // 如果是第一个工作/项目标题，先添加对应的二级标题
    if (isInternship && !hasAddedInternshipHeader) {
        result.append("\n## 实习经历\n");
        hasAddedInternshipHeader = true;
        currentSectionType = "实习经历";
    } else if (!isInternship && !hasAddedProjectHeader) {
        result.append("\n## 项目经验\n");
        hasAddedProjectHeader = true;
        currentSectionType = "项目经验";
    }
    
    result.append("\n### ").append(trimLine).append("\n");
    continue;
}
```

**作用**：
- 遇到第一个工作/项目标题时，先判断类型（实习/项目）
- 如果还没有对应的二级标题，先添加 `## 实习经历` 或 `## 项目经验`
- 然后再添加三级标题 `### 具体标题`
- 确保标题在内容前面

#### 2.4 去重处理

**新增逻辑**：
```java
// 去重：移除重复的标题
String finalResult = result.toString();
// 使用正则表达式移除重复的标题（相同标题只保留第一个）
// 匹配 "## 实习经历" 或 "## 项目经验" 或 "## 技能清单"
finalResult = finalResult.replaceAll("(## (实习经历|项目经验|技能清单)\\n)+", "## $2\n");
// 规范化换行
finalResult = finalResult.replaceAll("\n{3,}", "\n\n").trim();
```

**作用**：
- 使用正则表达式 `(## (实习经历|项目经验|技能清单)\n)+` 匹配重复的标题
- 替换为单个标题 `## $2\n`，确保每个分类的标题只出现一次
- 规范化换行符，移除多余的空白行

## 后续优化

### 支持技能相关标题的多种变体

**问题**：简历中可能使用"技能栈"、"技能清单"、"技术栈"等不同表述

**解决方案**：添加 `isSkillSectionTitle()` 方法，统一判断技能相关的标题

**代码实现**：
```java
/**
 * 判断是否为技能相关的标题（支持多种变体）
 * 支持：技能清单、技能栈、技术栈、专业技能、技术技能等
 */
private boolean isSkillSectionTitle(String title) {
    if (title == null || title.isEmpty()) {
        return false;
    }
    String lowerTitle = title.toLowerCase();
    // 支持多种变体：技能清单、技能栈、技术栈、专业技能、技术技能等
    return lowerTitle.contains("技能清单") || 
           lowerTitle.contains("技能栈") || 
           lowerTitle.contains("技术栈") ||
           lowerTitle.contains("技能") || 
           lowerTitle.contains("技术") ||
           lowerTitle.equals("技能清单") ||
           lowerTitle.equals("技能栈") ||
           lowerTitle.equals("技术栈");
}
```

**支持的变体**：
- ✅ 技能清单
- ✅ 技能栈
- ✅ 技术栈
- ✅ 专业技能
- ✅ 技术技能
- ✅ 其他包含"技能"或"技术"的标题

**效果**：无论简历中使用哪种表述，都能正确识别并统一标准化为"技能清单"
